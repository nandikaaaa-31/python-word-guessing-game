Python Word Guessing Game

About the Project

A fun and interactive word guessing game developed using Python.

Features

- Random word selection
- User guesses the hidden word
- Displays hints and feedback
- Tracks the guessing attempts

Technologies Used

- Python

How to Run

1. Download the project.
2. Open it in Python or VS Code.
3. Run the Python file.
4. Start guessing the word!
